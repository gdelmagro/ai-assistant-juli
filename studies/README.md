# Organización por estudio

Para cada estudio, creá una carpeta con un alias operativo autorizado que no identifique participantes ni revele información confidencial. Copiá `plantilla.md` como `seguimiento.md` y `tasks/plantilla-progreso.md` como `progress.md` dentro de esa carpeta. Completalos con Juli usando solo información no sensible autorizada. Si el nombre o el identificador del estudio es confidencial, usá un alias acordado.

Consultá el estado, la ficha y el seguimiento de esa carpeta cuando trabajes en el estudio. Para un trabajo de continuidad asociado, creá una subcarpeta en `trabajos/` con su propio `progress.md`. Mantené protocolos, registros, cronogramas y datos de participantes en los sistemas institucionales autorizados. Anotá una referencia segura a esos sistemas solo cuando esté permitido, sin credenciales ni enlaces privados.

Cuando Juli enseñe un proceso o indique una corrección para un estudio, registrá la información operativa segura en esa carpeta con fecha, origen y estado de verificación. Consultá la documentación vigente autorizada antes de aplicar requisitos del protocolo. Mantené cada proceso limitado al estudio al que corresponde y avisale a Juli qué guardaste.

Las carpetas de estudios pueden acompañar al proyecto en Git o en una migración. Usá un repositorio privado y revisá que su contenido esté autorizado para el destino, de acuerdo con las reglas institucionales. El asistente revisa pendientes cuando Juli se lo pide y no crea recordatorios automáticos por sí solo.
