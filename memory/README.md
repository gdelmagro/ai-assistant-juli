# Memoria local

Cuando Juli enseñe o corrija una preferencia reutilizable y no sensible, guardala en `memory/preferencias.local.md` como parte del trabajo. Anotá la fecha, la preferencia y su alcance. Por ejemplo, «Juli prefiere una tabla breve para el seguimiento semanal». Avisale brevemente qué guardaste. Juli puede consultar, corregir o borrar el archivo. Las preferencias autorizadas pueden acompañar al proyecto al migrarlo.
